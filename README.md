# Permadeath Reincarnated

## Créditos

## Sobre el proyecto

**Permadeath Reincarnated** es una recreación no oficial, hecha por fans, de la serie **Permadeath SMP**, creada originalmente por **ElRichMC** y **KernelFreeze**.

Este proyecto nació del amor por Permadeath SMP y busca recrear sus sistemas de dificultad, eventos y cambios progresivos dentro de Minecraft, junto con nuevas ideas y mecánicas propias.

El proyecto es gratuito y no tiene fines de lucro.
